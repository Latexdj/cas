Setting up CAS offline at a new school

School Server, offline tablets, learning materials and Offline Assessment

Teacher app build 8 or later
Student app build 15 or later

The CAS School Server is one Windows PC at the school. Over the school's own Wi-Fi, with no internet, it gives tablets past questions, learning materials and app updates, and runs Offline Assessment: tests, exercises, quizzes and exams that students take on the tablets. When the PC has internet it syncs with CAS by itself.

What the school needs

  • One Windows PC that stays on at school (Windows 10 or 11; an ordinary desktop is enough).
  • A cable from that PC to the main router.
  • The school's Wi-Fi: a router, with access points if needed.
  • Internet on the PC now and then (a mobile router is fine) for syncing with CAS.
  • The school's LM folder of learning materials, if it has one.

1. In CAS Super admin, once

  1. Make sure the school has the LMS module switched on. The School Server page, Offline Assessment and Notes for Tablets only appear when it is.
  2. In Super Admin › App Releases, check that the latest CAS Student and CAS Teacher apps are published. Every school server then copies them by itself.

2. On the school's PC About 20 minutes

  1. Copy CAS-School-Server.zip to the PC and unzip it.
  2. Give the PC a fixed address on the router (DHCP reservation), so phones and tablets always find it. The guide in the folder shows how.
  3. Right-click install.bat › Run as administrator. The server then starts with Windows, the firewall lets it through, and the PC is kept from sleeping.
  4. On that PC, open http://localhost:8787 and type the school's name. Later, from another laptop or phone on the school Wi-Fi, the admin opens these settings from the CAS admin portal: LMS › School Server › Open school server.
  5. Past questions: click Check online now. Apps: they arrive from CAS on their own; otherwise click Load app from file.
  6. Connect to CAS: in the admin portal, signed in as the school's admin, open LMS › School Server › Make a pairing code (it works once, for 15 minutes). On the server page, under Connect to CAS, type the school code and the pairing code and click Connect. The students and teachers copy across in a minute or two.

3. Learning materials and teacher notes About 15 minutes

  1. Tidy the school's LM folder first, on the PC where it is: one name for each kind of folder (VIDEO or VIDEOS, not both), the same layout in every form, and no app files or half-finished downloads.
  2. On the server page, under Learning materials, click Copy from this PC and type where the LM folder is, for example D:\LM. Its folders and files are copied as they are. Every tablet then gets exactly this tree.
  3. From now on, add files with Add material: choose the folder one level at a time (for example WASSCE, FORM 1, ELECTIVE SUBJECTS, TEXTBOOKS, General Arts, Economics). Files left at the top of LM are marked; use Move.
  4. Under Classes and teacher notes › Where notes go, set for each exam its levels and the folders for core and elective notes, using {level}, {programme} and {subject}. The defaults are: WASSCE/{level}/CORE SUBJECTS/TEACHER NOTES/{subject} WASSCE/{level}/ELECTIVE SUBJECTS/TEACHER NOTES/{programme}/{subject} Change the words to match the school's own folders. The Example box shows where a real class's notes would go.
  5. Under Classes, give each class its exam, level and programme or trade (for example General Arts). Under Subjects, tick the core subjects and check each subject's folder name matches its folder in LM. Click Save.

Teachers then add notes on the server's teacher page (Notes for tablets) or in CAS (Academics › Notes for Tablets, web or app). They reach every tablet on the school Wi-Fi.

4. Student tablets Once each

  1. Install the CAS Student app from the .apk file (USB cable or file share). This is the only install by hand.
  2. Connect the tablet to the school Wi-Fi and open the app. It finds the server, downloads past questions and learning materials, and from now on updates itself. Materials already copied onto the tablet by USB are not downloaded again.

5. Teachers Once each

  1. Android phones: install CAS Teacher, build 8 or later. On the school Wi-Fi, open More › Offline Assessment › Open Offline Assessment. It opens signed in.
  2. Laptops and iPhones: in the CAS teacher portal, open Academics › Offline Assessment › Open Offline Assessment while on the school Wi-Fi. It opens the server's teacher page signed in. If the school Wi-Fi has no internet, bookmark that page and sign in there with the teacher code and password.
  3. App updates arrive by themselves, from the school server or over the internet.

Check it works

  • The server page shows the school name, the past questions, both apps, and Connected to CAS with the number of students and teachers.
  • Learning materials shows the school's folders, and the Example box shows sensible folders for notes.
  • A tablet on the Wi-Fi shows past questions and the same LM folders, and appears in the server's list of tablets.
  • A teacher adds a note and creates a short test; a student sees the note and takes the test, and it shows under Results.

If something doesn't work

A tablet or phone can't find the serverIt is probably on mobile data, not the school Wi-Fi. Or type the address shown on the server page using Enter address in the app.
Students or teachers can't sign in to Offline AssessmentThe server isn't connected to CAS yet (step 2.6), or the PC hasn't been online since a new student was added.
A teacher's notes say "classes not placed"Those classes have no exam and level yet under Classes and teacher notes.
Notes made a second set of foldersThe words in Where notes go or a subject's folder name don't match the school's folders. Correct them and click Save; notes move to match.
The server page doesn't openRestart the PC; the server starts by itself. Or open Task Scheduler, right-click CAS School Server › Run.
A new app version isn't offeredPublish it in App Releases (or load it on the server page). Close and reopen the app on the Wi-Fi.
