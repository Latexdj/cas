Past questions

Online updates run every 30 minutes whenever this PC has internet. Without internet, load the .zip downloaded from Super Admin, Past Questions.

Apps

Load a newer CAS Student or CAS Teacher .apk; the server tells them apart. Tablets and teachers' phones on the Wi-Fi then offer to install it. When this PC has internet, new versions published in CAS arrive by themselves.

Connect to CAS (Offline Assessment)

In CAS, open LMS, School Server, and click Make a pairing code. This PC needs internet to connect.
